# Брачное агентство «Сердце»

Учебный проект — информационная система брачного агентства: настольное приложение
Windows Forms на C# (.NET Framework 4.7.2) с локальной базой данных SQL Server
`BrachnoeAgentstvo`. Доступ к данным построен на типизированном `DataSet`
(`BrachnoeAgentstvoDataSet.xsd`) с `TableAdapter` / `BindingSource` / `BindingNavigator` —
классический сценарий ADO.NET в Visual Studio.

## Возможности

- **Справочники** (должности, знаки зодиака, типы отношений, национальности,
  дополнительные услуги) — просмотр, добавление, редактирование и удаление записей
  через `BindingNavigator`.
- **Карточки клиентов и сотрудников** — ввод и правка всех полей записи, выбор
  связанных справочных значений (знак зодиака, тип отношений, национальность, должность).
- **Оформление услуг (заказов)** — привязка заказа к клиенту, сотруднику и до трёх
  дополнительных услуг с расчётом стоимости.
- **Отчёт «Отдел кадров»** — таблица по представлению с сортировкой по любому
  из четырёх ключевых полей, поиском по ФИО/должности и фильтром по должности.
- **Отчёт «Список клиентов»** — фильтры по знаку зодиака, типу отношений,
  национальности, семейному положению и подстроке в хобби.
- **Отчёт «Список услуг»** — фильтры по дате, сотруднику и услуге
  (поиск по трём полям услуги заказа).
- **Заставка** при запуске приложения.

## Быстрый старт

1. Клонировать репозиторий.
2. Присоединить базу данных:
   - **Вариант A (SQL Server Express):** в SSMS выполнить
     *Attach database* → выбрать файл `BrachnoeAgentstvo.mdf` из корня репозитория.
   - **Вариант B (LocalDB):** строка подключения с автоматическим присоединением файла
     уже приведена в файле `практика.exe.config`:
     ```
     Data Source=(LocalDB)\MSSQLLocalDB;AttachDbFilename=|DataDirectory|\BrachnoeAgentstvo.mdf;Integrated Security=True;Connect Timeout=30
     ```
3. Проверить строку подключения в `App.config` и `Properties/Settings.settings`.
   В репозитории она указывает на сервер автора проекта:
   ```
   Data Source=WOLFY;Initial Catalog=BrachnoeAgentstvo;Integrated Security=True
   ```
   `WOLFY` — это имя компьютера/экземпляра SQL Server, на котором разрабатывался проект.
   На другой машине его нужно заменить на своё (например, `.\SQLEXPRESS` или
   `(LocalDB)\MSSQLLocalDB`) — иначе приложение не подключится к базе.
4. Открыть `практика.csproj` в Visual Studio и запустить (F5) либо собрать
   *Build → Build Solution* и запустить `bin\Debug\практика.exe`.
5. При старте появляется заставка (2 секунды), затем открывается главное меню.

> Файл `Readme.txt` в репозитории содержит краткую инструкцию:
> 1) Установить SQL Server Express и SQL Server Management Studio (SSMS);
> 2) в SSMS присоединить базу данных; 3) пробовать запускать.

### Связи

Внешние ключи в `BrachnoeAgentstvoDataSet.xsd` не объявлены — там описаны только
первичные ключи (ограничения `xs:unique`). Связи видны по полям-кодам и по составу
представлений:

- `Клиенты.Код_знака` → `Знаки_зодиака.Код_знака`
- `Клиенты.Код_отношения` → `Отношения.Код_отношения`
- `Клиенты.Код_национальности` → `Национальности.Код_национальности`
- `Сотрудники.Код_должности` → `Должности.Код_должности`
- `Услуги.Код_клиента` → `Клиенты.Код_клиента`
- `Услуги.Код_услуги_1 / _2 / _3` → `Дополнительные_услуги.Код_услуги`
- `Услуги.Код_сотрудника` → `Сотрудники.Код_сотрудника`

## Как реализован доступ к данным

- **`BrachnoeAgentstvoDataSet`** — типизированный `DataSet`, сгенерированный из
  `BrachnoeAgentstvoDataSet.xsd`; содержит по `DataTable` на каждую таблицу и
  представление, а также `TableAdapter` для выборки/обновления.
- **Загрузка и сохранение.** Каждая форма в `FormN_Load` вызывает
  `<таблица>TableAdapter.Fill(...)`, а по кнопке сохранения `BindingNavigator` —
  `BindingSource.EndEdit()` и `TableAdapter.Update(...)` либо
  `tableAdapterManager.UpdateAll(...)` (каскадное сохранение всех изменённых таблиц).
- **Привязка данных.** Поля ввода привязаны через `DataBindings`
  (например, `фИОTextBox` → `сотрудникиBindingSource.ФИО`), `DataGridView` —
  через `DataSource` = `BindingSource`, а `ComboBox` — через `DisplayMember` /
  `ValueMember` (ФИО клиента по `Код_клиента`, наименование услуги по `Код_услуги`).
- **Фильтрация** выполняется свойством `BindingSource.Filter`
  (синтаксис `DataView`): `Должность = '...'`, `Сотрудник LIKE '%...%'`,
  `(Услуга_1 = '...' OR Услуга_2 = '...' OR Услуга_3 = '...')`.
- **Сортировка** (Form10) — метод `DataGridView.Sort(column, direction)` по колонке,
  заголовок которой совпадает с выбранным в `comboBoxSortField` полем;
  направление задают `radioButtonAsc` / `radioButtonDesc`.

## Известные особенности и точки роста

- **Строка подключения привязана к машине разработчика.** `Data Source=WOLFY`
  (имя компьютера/экземпляра SQL Server) — на другом ПК приложение не подключится
  к базе. Стоит оставить универсальный вариант
  (`.\SQLEXPRESS` или `(LocalDB)\MSSQLLocalDB` + `AttachDbFilename`).
- **Нет обработки ошибок подключения.** Если база недоступна, форма падает с
  необработанным исключением; приветствовались бы `try/catch` вокруг `Fill`/`Update`
  и понятное сообщение пользователю.
- **В репозиторий закоммичены артефакты сборки и сама база:** папки `bin/` и `obj/`,
  файлы `BrachnoeAgentstvo.mdf` (~8 МБ), `BrachnoeAgentstvo_log.ldf` (~8 МБ),
  `практика.pdb` (~650 КБ). Обычно их выносят в `.gitignore`, а базу распространяют
  отдельным скриптом создания/наполнения.
- **Мёртвый код и дубликаты:** обработчики `button_Выход_Click`,
  `button_ОПрограмме_Click`, `button_Гистограмма_Click` остались без привязанных
  кнопок (кнопки «Выход», «О программе» и гистограмма отсутствуют в дизайнере);
  Form7 недоступна из меню; в Form11 два одинаковых обработчика сохранения; в Form10
  продублирован обработчик `comboBoxFilter_SelectedIndexChanged`.
- **Расхождения заголовков:** в Form12 дизайнер задаёт «Список клиентов», а код —
  «Список услуг (фильтры)»; в Form13 — «Список Клиентов» и «Список клиентов (фильтры)».
- **Сборка строк фильтров конкатенацией.** В Form13 апострофы в тексте хобби
  экранируются (`Replace("'", "''")`), а в Form10 и Form12 — нет: значение с
  апострофом сломает фильтр. Надёжнее использовать параметризованные запросы
  или `DataView.RowFilter` с предварительной проверкой ввода.
- **Ресурсы по умолчанию.** `Properties/Resources.resx` содержит шаблонные записи
  Visual Studio (`Name1`, `Color1`, `Bitmap1`, `Icon1`); файл `bin/Debug/splash.jpg`
  в коде не используется — заставка рисуется программно в Form14.
- **Отсутствуют** файл решения `.sln`, тесты, README с описанием (добавлен этим
  документом) и лицензия.
